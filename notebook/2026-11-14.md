 **Lessons:**
- Read compiler errors as "here's what I thought you meant."
- Warnings can mean the program is wrong even when it compiles.
- printf layout: printf("format", arg1, arg2); one specifier per argument.
- Lesson: struct size is rounded up to a multiple of its strictest member's
  alignment (8 for double), so arrays of structs stay aligned. Order changes
  where padding goes: int/char/double = 16 (3 bytes padding in the middle),
  double/int/char = 16 (3 bytes tail padding after the char, offsets 0, 8, 12).
